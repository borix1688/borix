這個網站是什麼

「旅圖誌」是一個旅遊資訊網站，精選四個來自不同國家的旅遊地點：日本京都、意大利羅馬、埃及開羅與秘魯庫斯科。每個地點都整理了歷史背景、文化特色、四個必去景點，以及旅行者真正用得著的實用資料，例如最佳季節、貨幣、語言、交通與簽證提示。

我們相信一趟好的旅行始於出發前的理解。知道一座城市為什麼長成今天的樣子，走在它的街道上就會看到完全不同的東西。如果你已經有心水，可以先去「目的地」頁比較四個地方，再進入詳細介紹。

本站以純 HTML、CSS 與 JavaScript 手寫完成，沒有使用任何前端框架或外部資源，並採用響應式設計，手機、平板與桌面都可以正常瀏覽。

常見問題

點擊問題就可以展開答案。

這個網站的資料從哪裡來？

內容整理自公開的旅遊資訊、各地官方旅遊局與博物館網站，再重新編寫成中文。資料以介紹及參考為目的，並非官方公告。

為什麼只介紹四個地點？

課程要求介紹四個來自不同國家的旅遊地點。與其蜻蜓點水介紹二十個城市，我們選擇把四個地方寫得足夠深入，包括歷史、文化、景點與實用資料。

網站上的圖片是真實照片嗎？

目前顯示的是暫代用的示意圖，只用來呈現版面效果。正式版本會換成實拍照片，更換方式可參考專案內的 README 檔案，裡面列出了每張圖片的檔名、建議內容與建議尺寸。

為甚麼沒有訂票或訂房功能？

本站是純前端的課堂習作，沒有後端伺服器與資料庫，因此只提供旅遊資訊，不會處理任何交易或個人資料。

我填了聯絡表單，你們會回覆嗎？

不會。表單只用來示範 JavaScript 的前端驗證，按下送出後資料不會傳送到任何地方，重新載入頁面就會消失。請勿在表單中輸入任何真實的個人資料。

簽證與安全提示可以直接照跟嗎？

不建議。各國的簽證政策、入境要求與安全狀況會隨時變動，出發前請務必查閱目的地官方領事館或入境部門的最新公告。
